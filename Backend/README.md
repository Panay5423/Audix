# Audix Backend API

Audix backend is built with **Node.js**, **Express 5 (ESM)**, **Mongoose**, and connects to the **Spotify Web API** and **Google Gemini LLM**.

## Environment Setup
Copy `.env.example` to `.env` and fill in credentials:
```bash
cp .env.example .env
```

## Running
```bash
npm install
npm start
# Or for auto-reload:
npm run dev
```

For full documentation and API references, see the main [README.md](../README.md).
